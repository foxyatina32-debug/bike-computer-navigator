# bike-computer-navigator

Велокомпьютер с навигацией для iPhone (Израиль, MTB и город): запись поездок, карты Israel Hiking / CyclOSM / OpenTopoMap, построение маршрутов под тип велосипеда (BRouter, OSRM, встроенный движок по OpenStreetMap), трассы из OSM, импорт GPX/KML/KMZ/TCX и ссылок, передача маршрута в Google Maps и Waze, офлайн-карты, голосовые команды.

Открывать в Safari по адресу https://foxyatina32-debug.github.io/bike-computer-navigator/dima/ , затем «Поделиться» → «На экран Домой».

Обновления приходят сами: при каждом возвращении в приложение и раз в 30 минут оно сверяет свою сборку с `version.json` на сайте и перезагружается в новую версию (во время записи поездки или навигации — после них). При выпуске новой версии номер в `version.json` и `APP_BUILD` в `index.html` меняются вместе.

## Google Карты и маршруты Google (необязательно)

Без ключа всё работает на бесплатных картах и маршрутизаторах. С ключом Google появляются карта Google, движок маршрутов «Google» (велорежим Google Maps) и поиск адресов Google.

1. console.cloud.google.com → создать проект и привязать платёжный аккаунт (в пределах бесплатных лимитов Google ничего не списывает).
2. «APIs & Services» → «Library» → включить **Map Tiles API**, **Routes API** и при желании **Places API (New)**.
3. «Credentials» → «Create credentials» → «API key». В ограничениях ключа: «Websites» → `https://foxyatina32-debug.github.io/*`; «API restrictions» → только эти три API.
4. В приложении: Настройки → «Для продвинутых» → «Google Карты» → вставить ключ → «Сохранить». Приложение проверит карту и маршруты.

Что ещё даёт ключ Google: «+ Маршрут» → «Что рядом» (а в навигации — «Что по пути») показывает веломагазины, магазины, заправки и кафе рядом или впереди по маршруту (Places API (New), Nearby Search); у значка — «Заехать сюда»: маршрут пройдёт через эту точку к тому же финишу. Поиск адресов с ключом идёт через Google (точные номера домов).

Без ключа: кнопка «Google Maps» передаёт в Google Maps ключевые повороты маршрута (до 9 промежуточных точек, упрощение Рамера — Дугласа — Пейкера), чтобы Google не увёл на шоссе. В приложении Google Maps и на компьютере Google принимает до 9 точек, в мобильном браузере — до 3. «Добавить по ссылке» понимает любые ссылки Google Maps: маршрут, место, точку, а короткие maps.app.goo.gl разворачивает через allorigins.win / corsproxy.io.

Маршруты Google: «Маршруты» → «Построить» → движок «Google», или «Из точки в точку» с покрытием «По дорогам». Велорежим Google — бета: велодорожки учтены не везде, тропы и бездорожье Google не знает (для MTB — BRouter или GPX). Маршруты и поиск Google показываются на карте Google. Высоты для профиля берутся из Open-Meteo.

## Яркое солнце

Настройки → «Карта и вид» → «Экран»: «🌙 Тёмный» (как было), «☀️ Яркое солнце» — светлые кнопки, панель поездки, баннер поворотов и меню на карте, лучше видно на ярком солнце; «🌓 По солнцу» — светлый от восхода до заката (по вашему месту), тёмный вечером и ночью. Списки и настройки остаются тёмными — их открывают на остановке.

## Цвет маршрута и значок

Настройки → «Карта и вид» → «Маршрут и значок на карте»: цвет линии маршрута (11 готовых или любой свой) и значок «это вы» — стрелка, велосипед, горный велосипед, самокат, скутер, мотоцикл, машина, бег, пешком, с собакой, звезда. У значков маленький указатель показывает направление движения.

## Далеко от маршрута и обратная сторона

Если при запуске навигации вы не на маршруте, приложение спрашивает, как быть: «Проложить путь до старта на велосипеде» (затем весь маршрут), «К ближайшей точке маршрута», «⇆ Ехать в обратную сторону» — если финиш ближе старта, «До старта в Google Maps» — если до маршрута больше 1,5 км (навигация Велокомпа остаётся включённой), или «Продолжить навигацию — доберусь сам» (стрелка показывает на маршрут). Проехать сохранённый маршрут в другую сторону: «Маршруты» → «Мои» → «⋯» → «⇆ Обратно».

## Кольцом на ходу

После выбора маршрута «в одну сторону» рядом с 🎤 на 15 секунд появляется маленькая кнопка «⟳ Кольцом»: одно нажатие — обратный путь к старту по другим дорогам (если их нет — той же). Не нажали — кнопка исчезает. Позже то же самое: «Маршруты» → «Активная навигация» → «⟳ Назад другой дорогой» или «⇄ Туда и обратно».

## Голосовые команды

Кнопка 🎤 под «Маршрут» на карте. Скажите:

- «поехали домой» — маршрут от вашего места до дома;
- «поехали в Модиин», «отвези меня на пляж Гордон» — поиск места и маршрут;
- «поехали 31,95 34,88» — маршрут до координат;
- «запомни дом» (когда вы дома) или «запомни дом улица Герцль 10, Петах-Тиква» — задать дом.
- «останови навигацию» / «стоп навигация» — остановить навигацию; «отмена» — отменить команду; «не …» (например, «не едь домой») — ничего не делать.

Голос включается только кнопкой 🎤: сам микрофон не слушает (режим «Привет, Вело» отключён). Когда телефон заблокирован или открыто другое приложение, iPhone не даёт веб-приложению микрофон.

Адрес можно и напечатать в поле панели: при вводе появляются подсказки, у каждой кнопки ➜ (поехали) и 🏠 (сделать домом). Русские названия улиц ищутся по их написанию на иврите (Шпринцак 16, Петах-Тиква → שפרינצק 16 פתח תקווה) — так находится и в «Из точки в точку». Подсказки при наборе — Photon (photon.komoot.io), бесплатно, без ключа; полный поиск (Nominatim или Google) — по кнопке «Найти» на клавиатуре и для голосовых команд: правила Nominatim не разрешают поиск по мере набора. С ключом Google (Настройки → «Для продвинутых» → «Google Карты», нужен Places API (New)) полный поиск идёт через Google — точные номера домов, а при наборе Google спрашивается, только если Photon не нашёл номер дома; маршрут к такому адресу показывается на карте Google. Если адрес не нашёлся нигде, в подсказках есть «Открыть в Google Maps» — приложение Google Maps найдёт его само и поведёт на велосипеде.

Работает на русском, иврите и английском (язык приложения). Маршрут строится тем же движком, что выбран в «Маршруты → Построить», и сразу запускается навигация. Распознавание речи — встроенное в Safari, без ключей и платных сервисов. Если в режиме «на экране Домой» распознавание недоступно, команду можно надиктовать в поле панели кнопкой 🎤 на клавиатуре iPhone. Дом хранится только на этом телефоне.

## Свой прокси (Cloudflare Worker)

Необязательный помощник для Pro-режима. Он скачивает маршруты с сайтов, которые не дают браузеру загрузить файл, разворачивает короткие ссылки Google (`maps.app.goo.gl`). Это не открытый прокси: он отвечает только самому приложению и только для сайтов с маршрутами. Бесплатного тарифа Cloudflare хватает с большим запасом.

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) (бесплатно).
2. **Workers & Pages** → **Create** → **Create Worker** → имя, например `velocomp` → **Deploy**.
3. **Edit code** → удалите пример → вставьте весь файл [`cloudflare-worker.js`](cloudflare-worker.js) из этого репозитория → **Deploy**.
4. Адрес воркера вида `https://velocomp.<ваше-имя>.workers.dev`. В Велокомпе: Настройки → «Для продвинутых» → включить «Pro-режим» → «Свой прокси (Cloudflare Worker)» → вставить адрес → «Проверить и сохранить».

После этого приложение пробует так: напрямую → через ваш воркер → (если включено «Через прокси») через общие allorigins.win и corsproxy.io.

Переменные воркера (**Settings → Variables and Secrets**), все необязательные:
- `ALLOWED_ORIGINS` — адреса приложения, которым можно пользоваться воркером. По умолчанию `https://foxyatina32-debug.github.io`.
- `STRAVA_CLIENT_ID`, `STRAVA_CLIENT_SECRET` — заготовка в воркере; в самом приложении подключения Strava пока нет (поездки в Strava — через файл GPX).

## Аккаунт (вход по почте и паролю)

Настройки → «👤 Аккаунт»: регистрация и вход по почте и паролю. Поездки, маршруты, свои участки дорог и настройки (вместе с ключами карт) сами сохраняются в аккаунте — после каждого изменения, при запуске и раз в 5 минут; без интернета изменения ждут и уходят, когда связь появится. На другом телефоне достаточно войти под той же почтой — всё появится там. «Забыли пароль?» присылает письмо для смены пароля. Пароль на телефоне не хранится. Если одно и то же изменили на двух телефонах, остаётся более позднее изменение.

Аккаунты работают через Firebase (Google), бесплатно. Один раз нужно создать проект:

1. [console.firebase.google.com](https://console.firebase.google.com) → **Create a project** (Google Analytics можно выключить).
2. **Build → Authentication → Get started → Sign-in method → Email/Password** → включить → **Save**.
3. **Build → Firestore Database → Create database** → расположение, например `eur3 (europe-west)` → **Start in production mode**. Вкладка **Rules** → заменить всё на текст ниже → **Publish**:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

4. ⚙️ **Project settings → General → Your apps → `</>` (Web)** → любое имя → **Register app**. Из показанного `firebaseConfig` нужны два значения: `apiKey` и `projectId`. Их вписывают в `dima/index.html` в строку `const FB = Object.assign({ apiKey: '', projectId: '' }, …` — это не секрет: ключ Firebase только называет проект, а чужие данные закрыты правилами из шага 3.
5. Необязательно: Google Cloud Console → «APIs & Services» → «Credentials» → этот ключ → «Websites» → `https://foxyatina32-debug.github.io/*`; **Authentication → Templates** → язык писем — русский.

Бесплатного тарифа Firebase (Spark) хватает с запасом: длинная поездка занимает в базе около 0,5–1 МБ (трек сжимается), лимит — 1 ГБ.

## Резервная копия

Настройки → «Данные» → **📦 Сохранить копию** — откроется меню «Поделиться», куда сохранить файл, выбираете вы. В одном файле лежат все поездки, маршруты, свои участки дорог и настройки, включая раскладку карточек. Личные ключи карт (Google, Thunderforest, Mapy.com) в файл не попадают — файл могут переслать; после восстановления на новом телефоне их нужно вставить заново. «Восстановить из файла» возвращает всё остальное, подходит и для переезда на новый телефон.
