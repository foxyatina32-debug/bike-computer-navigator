# bike-computer-navigator

Велокомпьютер с навигацией для iPhone (Израиль, MTB и город): запись поездок, карты Israel Hiking / CyclOSM / OpenTopoMap, построение маршрутов под тип велосипеда (BRouter, OSRM, встроенный движок по OpenStreetMap), трассы из OSM, импорт GPX/KML/KMZ/TCX и ссылок, передача маршрута в Google Maps и Waze, офлайн-карты, голосовые команды.

Открывать в Safari по адресу GitHub Pages, затем «Поделиться» → «На экран Домой».

Обновления приходят сами: при каждом возвращении в приложение и раз в 30 минут оно сверяет свою сборку с `version.json` на сайте и перезагружается в новую версию (во время записи поездки или навигации — после них). При выпуске новой версии номер в `version.json` и `APP_BUILD` в `index.html` меняются вместе.

## Google Карты и маршруты Google (необязательно)

Без ключа всё работает на бесплатных картах и маршрутизаторах. С ключом Google появляются карта Google, движок маршрутов «Google» (велорежим Google Maps) и поиск адресов Google.

1. console.cloud.google.com → создать проект и привязать платёжный аккаунт (в пределах бесплатных лимитов Google ничего не списывает).
2. «APIs & Services» → «Library» → включить **Map Tiles API**, **Routes API** и при желании **Places API (New)**.
3. «Credentials» → «Create credentials» → «API key». В ограничениях ключа: «Websites» → `https://foxyatina32-debug.github.io/*`; «API restrictions» → только эти три API.
4. В приложении: Профиль → «Google Карты» → вставить ключ → «Сохранить». Приложение проверит карту и маршруты.

Что ещё даёт ключ Google: «+ Маршрут» → «Что рядом» (а в навигации — «Что по пути») показывает веломагазины, магазины, заправки и кафе рядом или впереди по маршруту (Places API (New), Nearby Search); у значка — «Заехать сюда»: маршрут пройдёт через эту точку к тому же финишу. Поиск адресов с ключом идёт через Google (точные номера домов).

Без ключа: кнопка «Google Maps» передаёт в Google Maps ключевые повороты маршрута (до 9 промежуточных точек, упрощение Рамера — Дугласа — Пейкера), чтобы Google не увёл на шоссе. В приложении Google Maps и на компьютере Google принимает до 9 точек, в мобильном браузере — до 3. «Добавить по ссылке» понимает любые ссылки Google Maps: маршрут, место, точку, а короткие maps.app.goo.gl разворачивает через allorigins.win / corsproxy.io.

Маршруты Google: «Маршруты» → «Построить» → движок «Google», или «Из точки в точку» с покрытием «По дорогам». Велорежим Google — бета: велодорожки учтены не везде, тропы и бездорожье Google не знает (для MTB — BRouter или GPX). Маршруты и поиск Google показываются на карте Google. Высоты для профиля берутся из Open-Meteo.

## Голосовые команды

Кнопка 🎤 под «Маршрут» на карте. Скажите:

- «поехали домой» — маршрут от вашего места до дома;
- «поехали в Модиин», «отвези меня на пляж Гордон» — поиск места и маршрут;
- «поехали 31,95 34,88» — маршрут до координат;
- «запомни дом» (когда вы дома) или «запомни дом улица Герцль 10, Петах-Тиква» — задать дом.

Без кнопки: Профиль → «Привет, Вело». Пока приложение открыто на экране, скажите «Привет, Вело, поехали домой» одной фразой или «Привет, Вело», дождитесь «Слушаю» и скажите команду. Подходят также «Хей / Эй / Окей, Вело», на иврите «היי ולו», на английском «Hey Velo». Зелёная точка на кнопке 🎤 — приложение слушает. Когда телефон заблокирован или открыто другое приложение, iPhone не даёт веб-приложению микрофон.

Адрес можно и напечатать в поле панели: при вводе появляются подсказки, у каждой кнопки ➜ (поехали) и 🏠 (сделать домом). Русские названия улиц ищутся по их написанию на иврите (Шпринцак 16, Петах-Тиква → שפרינצק 16 פתח תקווה) — так находится и в «Из точки в точку». Подсказки при наборе — Photon (photon.komoot.io), бесплатно, без ключа; полный поиск (Nominatim или Google) — по кнопке «Найти» на клавиатуре и для голосовых команд: правила Nominatim не разрешают поиск по мере набора. С ключом Google (Профиль → «Google Карты», нужен Places API (New)) полный поиск идёт через Google — точные номера домов, а при наборе Google спрашивается, только если Photon не нашёл номер дома; маршрут к такому адресу показывается на карте Google. Если адрес не нашёлся нигде, в подсказках есть «Открыть в Google Maps» — приложение Google Maps найдёт его само и поведёт на велосипеде.

Работает на русском, иврите и английском (язык приложения). Маршрут строится тем же движком, что выбран в «Маршруты → Построить», и сразу запускается навигация. Распознавание речи — встроенное в Safari, без ключей и платных сервисов. Если в режиме «на экране Домой» распознавание недоступно, команду можно надиктовать в поле панели кнопкой 🎤 на клавиатуре iPhone. Дом хранится только на этом телефоне.
