# Тесты

`regression.py` — регрессионные проверки ошибок, найденных при QA-аудите. Приложение запускается в настоящем Chromium (размер iPhone, эмуляция GPS) с настоящими Leaflet 1.9.4 и leaflet-rotate 0.2.8; внешние сервисы (тайлы карт, BRouter, Overpass, Nominatim) подменены заглушками — их реальная работа этими тестами не проверяется.

Нужно: Python 3, `pip install playwright`, Chromium для Playwright (или путь к нему в `CHROME_PATH`), git (библиотеки скачиваются в `tests/.cache` при первом запуске).

```
python3 tests/regression.py
```

`ride.py` — целая поездка, смоделированная посекундно с ускоренными часами: импорт GPX, повороты и голос, стоянка (автопауза, в том числе когда GPS перестаёт присылать точки), съезд с маршрута и перестроение, перезагрузка приложения посреди поездки, финиш и сохранение, старт с середины маршрута, скачок GPS, слабый сигнал, кольцо в обратную сторону. Шум GPS моделируется плавным дрейфом, как у iPhone.

`screens.py` — все экраны на iPhone SE и iPhone 15 Pro на русском, иврите и английском: нет ошибок JS, ничего не вылезает за экран, нет непереведённого текста.

`voice.py` — голосовые команды: разбор фраз на русском, иврите и английском («поехали домой», координаты, место, «запомни дом») и весь путь кнопка 🎤 → маршрут → навигация, режим «Привет, Вело». Распознавание речи подменено заглушкой, которая «слышит» заданную фразу.

`update.py` — автообновление: новая версия на сайте перезагружает приложение сразу, а во время поездки или навигации — после неё; без бесконечных перезагрузок. Номер сборки в `index.html` (`APP_BUILD`) и в `version.json` должен совпадать — тест это проверяет.

`gmaps.py` — Google Maps: ключевые точки поворотов в ссылках Google Maps, импорт любых ссылок Google (короткие maps.app.goo.gl, место, точка), «Что рядом / по пути» (Places Nearby) и «Заехать сюда».

`look.py` — цвет маршрута и значок на карте из Профиля, сохраняются после перезапуска.

`fit.py` — файлы FIT (Garmin, Wahoo, Zwift, Komoot): импорт тренировки в Историю (точки, пульс, калории из файла, тип, без дублей) и как маршрут с запуском навигации; порядок байт little/big endian, сжатые метки времени, поля разработчика, файл курса, повреждённый файл. FIT-файлы генерируются самим тестом.

`ihm.py` — ссылки «Поделиться» Israel Hiking Map / mapeak.com: маршрут с названием и отмеченными точками, ссылка внутри сообщения WhatsApp, несколько маршрутов в одной ссылке, старая форма ?s=, запасной mapeak.com, сообщения об ошибках на трёх языках. API подменён заглушкой по формату из исходников Israel Hiking.

`offroute.py` — съезд с маршрута и езда против него посреди поездки: GPX-трек, по которому уже проехали 300+ м, не разворачивается целиком — баннер «Развернитесь», голосом, с повтором каждые 40 с; без автоперестроения или без сети — один раз голосом «Вы сошли с маршрута» и стрелка обратно к маршруту; перестроение назад к маршруту не срезает маршрут к близкому финишу (подкова); маршрут не пропадает.

`nearroute.py` — запуск маршрута, стоя рядом с его дорогой (20–120 м): всегда окно выбора — продолжить отсюда / к ближайшей точке / до старта.

`nearlist.py` — «Маршруты рядом со мной» в «Трассах»: маршруты OpenStreetMap (база Israel Hiking Map) и свои сохранённые, ближайшие первыми, не больше 15, радиус 5/15/30 км запоминается; нажатие на маршрут — просмотр на карте с карточкой (длина, время, кольцо или в одну сторону, до старта), «← К списку» и «Поехали»; «Поехали» в списке запускает навигацию с выбором старта; без Overpass свои маршруты всё равно показываются; иврит и английский без непереведённого текста.

`geometry.py` — геометрия маршрута: ответы BRouter и OSRM без перестановки широты и долготы, линия на карте точка в точку совпадает с навигационной; маршруты OSM склеиваются из кусков в любом порядке и направлении, дыра до 300 м перекрывается, далёкий кусок и запасные ветки («alternative») не пришиваются фантомной прямой; при перестроении остаток маршрута — исходный точка в точку (с высотами), путь назад доходит до маршрута, даже если маршрутизатор остановился на дороге рядом, и без ложного разворота, если он «перелетел» точку возврата.

`audit97.py` — геолокация и экран в поездке: баннер «Нет доступа к геолокации» с шагами для iPhone Safari, Chrome на iPhone, Android и компьютера, кнопка «Повторить» и подхват разрешения без нажатия; «Неточная геопозиция», когда выключена «Точная геопозиция»; без GPS планирование стартует с последней известной точки (до 30 мин); кнопка 3D приглушена без интернета; режим «В поездке» прячет лишние кнопки в движении и возвращает их по касанию карты и на остановке; иврит и английский.
