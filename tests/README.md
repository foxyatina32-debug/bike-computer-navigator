# Тесты

`regression.py` — регрессионные проверки ошибок, найденных при QA-аудите. Приложение запускается в настоящем Chromium (размер iPhone, эмуляция GPS) с настоящими Leaflet 1.9.4 и leaflet-rotate 0.2.8; внешние сервисы (тайлы карт, BRouter, Overpass, Nominatim) подменены заглушками — их реальная работа этими тестами не проверяется.

Нужно: Python 3, `pip install playwright`, Chromium для Playwright (или путь к нему в `CHROME_PATH`), git (библиотеки скачиваются в `tests/.cache` при первом запуске).

```
python3 tests/regression.py
```

`ride.py` — целая поездка, смоделированная посекундно с ускоренными часами: импорт GPX, повороты и голос, стоянка (автопауза, в том числе когда GPS перестаёт присылать точки), съезд с маршрута и перестроение, перезагрузка приложения посреди поездки, финиш и сохранение, старт с середины маршрута, скачок GPS, слабый сигнал, кольцо в обратную сторону. Шум GPS моделируется плавным дрейфом, как у iPhone.

`screens.py` — все экраны на iPhone SE и iPhone 15 Pro на русском, иврите и английском: нет ошибок JS, ничего не вылезает за экран, нет непереведённого текста.

`voice.py` — голосовые команды: разбор фраз на русском, иврите и английском («поехали домой», координаты, место, «запомни дом») и весь путь кнопка 🎤 → маршрут → навигация, режим «Привет, Вело». Распознавание речи подменено заглушкой, которая «слышит» заданную фразу.

`update.py` — автообновление: новая версия на сайте перезагружает приложение сразу, а во время поездки или навигации — после неё; без бесконечных перезагрузок. Номер сборки в `index.html` (`APP_BUILD`) и в `version.json` должен совпадать — тест это проверяет.

`gmaps.py` — Google Maps: ключевые точки поворотов в ссылках Google Maps, импорт любых ссылок Google (короткие maps.app.goo.gl, место, точка), «Что рядом / по пути» (Places Nearby) и «Заехать сюда».

`look.py` — цвет маршрута и значок на карте из Профиля, сохраняются после перезапуска.

```
python3 tests/look.py
python3 tests/gmaps.py
python3 tests/update.py
python3 tests/voice.py
python3 tests/ride.py
python3 tests/screens.py
```
